# SynapseBrain

多 AI 协作讨论画布。多个 AI 分方向就一个议题并行讨论，讨论过程中自动生成「关键球」——每个关键球是一个方向的精确表达；人与 AI 在同一块黑底画布上协作：拖入文件让 AI 研读、随时插话、用手势和语音直接控场。

**在线体验（演示模式，零安装零消耗）**：https://shxshx0802.github.io/SynapseBrain/

## 快速开始

```bash
npm install
npm run dev        # http://localhost:7100
```

**接入真实模型（二选一）**：

1. **界面按钮（推荐）**：主页或讨论室右上角点「接入 API」，粘贴 Moonshot API Key → 测试连接 → 保存并重启。Key 只存在本浏览器 localStorage，随时可清除退回演示模式；线上版本同样可用。
2. **环境变量**：复制 `.env.example` 为 `.env` 并填入 `VITE_MOONSHOT_API_KEY`（适合自建部署，构建期烘焙）。

不配置则运行**演示模式**（本地话术池，零消耗，全部功能可用）。

```bash
npm run build      # 产物在 dist/
npm run deploy     # 一键构建并发布到 GitHub Pages（自动切子路径 base + REST 推送 gh-pages）
```

## 功能总览

### 讨论引擎

- **多 AI 分工讨论**：每个房间围绕一个议题，AI 各自从技术、商业、风险等方向并行发言、互相回应
- **人类随时插话**：输入或语音发言后，相关方向的 AI 优先回应
- **额度体系**：每个 AI 有 token 额度，发言即扣费；降档机制（额度低于 20% 自动缩短发言）；用尽进入「待批准」，点「放行 50%」或「继续讨论」即重整额度复活
- **AI 额度调度官**：监控各方向「产出/消耗」效率，自动暂停低效方向、回补相关方向，**全员耗尽时自动回补 30% 防止讨论锁死**
- **主持人 AI**：周期性总结各方向最新动态，生成讨论 digest
- **收敛讨论**：把相近的关键球（拼接簇）聚成结论卡片；点击后进入**实时刷新模式**，结论随讨论持续更新（卡片并入各方向最新发言要点）
- **讨论报告一键导出**：Markdown 报告含议题、结论、关键球关系（拼接解读）、各方向**完整**讨论记录、额度消耗表
- **时间轴回放**：拖动回放条，画布按讨论进程逐步重现关键球的生成与拼接过程
- **房间持久化**：讨论消息、关键球布局、额度、结论全部本地保存，刷新/重进不丢

### 关键球画布

- 讨论中 AI 自动提炼「值得做成关键球」的概念，出生点按同作者球簇黄金角螺旋展开，**保证不与现有球重叠**
- 灰色球体待机常发**阵阵白色光波**（双层画布：goo 滤镜层画球体/融球，独立层画光波）
- 两个球靠近：**融球桥接 + 阵阵光波 + 轻微震动**，AI 说出两者的关系解读（气泡显示）
- 整理布局：一键同心环形层层递进 + 自动取景
- 减少动态效果开关：只关闭震动/脉冲强反馈，**不影响待机光波与黑底主题**

### 手势控制（右下角控制坞「启手势」，需摄像头）

先**张开双手**唤醒（出现「已唤醒」徽章），之后：

| 手势 | 作用 |
|---|---|
| 移动食指 | 光标跟随指向；**靠近关键球自动减速**（光标环变琥珀色）防手滑 |
| 左手左右摆动 | 放大画布 |
| 右手左右摆动 | 缩小画布 |
| 右手握拳 | 关键球上 = 抓住拖动该球；空白处 = 拖动整个画布 |
| 左手握拳 | 双击打开光标处的关键球内容 |
| 左手手背朝向摄像头 | 退出已打开的内容面板 |
| 双手中心偏移 | 画布 3D 倾斜（摆动/抓取时锁定） |
| 双手离开画面约 2.5 秒 | 自动退出手势模式 |

- 手指弯曲有阈值，轻微弯曲不会误判为握拳
- 识别出的左右手与实际相反时点「换」开关校准
- 交互通过向关键球派发合成指针事件实现，与鼠标完全复用同一套逻辑

### 语音参与（控制坞「启语音」，需麦克风）

说唤醒词「**小K**」→ 提示音后 6 秒内说出观点 → 自动送入讨论。**语音控场指令**：「小K 暂停 / 继续 / 整理 / 收敛 / 放大 / 缩小 / 导出 / 回放」直接控场；同句说出「小K 暂停」立即执行。未说完自动续时，安静 6 秒自动提交。

### 文件讨论

把 PDF / DOCX / 图片 / 文本文件**拖入画布**：自动提取内容 → 展示摘要 → 所有 AI 围绕文件结合议题讨论（图片走多模态）。

### 邀请协作者（多人同 room）

房主点顶栏「**邀请**」→ 复制链接发给他人，对方打开 `room/:id?join=1` 即以**协作者模式**进入同一房间：

- **协作者能**：实时观看讨论流 / 关键球 / 额度的同步更新（快照跟随房主状态）；随时把文件拖入画布——文件在本地提取后经协作通道发给房主，由房主侧 AI 阅读并推进讨论
- **操控权归房主**：暂停 / 收敛 / 整理布局 / 回放 / 额度放行 / 插话输入只在房主页面渲染，协作者界面物理隔离地不呈现这些控件
- 同步基于 MQTT 公共 broker（WebSocket），静态托管免自建服务器；状态快照单向广播 + 700ms 限流 + 心跳在线计数
- 提示：房间数据经过公共消息中转，请勿在讨论中发送敏感机密内容

### 稳定性：崩溃自检装甲

针对「点击后页面黑屏」历史问题构建的三层防护：

1. **错误边界**：全局 + 手势坞局部双层边界，任何渲染异常变成可见错误卡，不再整页黑屏
2. **画布自愈**：绘制循环先排下一帧再绘制 + 单帧异常保护（rAF 链条永不断裂）；GPU 上下文丢失监听自动恢复
3. **心跳崩溃记录**：每 3 秒心跳 + 异常退出检测，崩溃后刷新页面可见「上次会话异常退出」卡片与最后记录的错误

## 页面

| 路由 | 说明 |
|---|---|
| `/` | 主页：创建 / 管理不同项目的讨论房间，互不混淆 |
| `/room/:id` | 讨论室：画布 + 讨论面板 + 手势语音控制坞 |
| `/room/:id?join=1` | 协作者模式：只读观看 + 拖文件参与（由房主邀请链接进入） |
| `/lab` | 手势 & 语音实验室：识别能力的独立测试页 |

## 技术要点

- 手势：MediaPipe HandLandmarker（本地模型 + WASM，离线可用），CPU 推理规避部分显卡驱动崩溃；480×360 输入 + 每帧去重
- 语音：Chromium 内置语音识别（`webkitSpeechRecognition`），唤醒词 + 控场指令匹配，断线自动重连（定时器全生命周期清理）
- 关键球渲染：双层 canvas（SVG goo 滤镜层画球体融球 + 无滤镜层画光波细线）；HTML 球面覆盖避免滤镜重影
- 模拟手势事件复用鼠标交互链路，手势/鼠标零分叉
- API 接入：Vite env（构建期）+ localStorage（运行时）双层配置，运行时优先；OpenAI 兼容 chat/completions 直连
- React 19 + Vite + TypeScript + Tailwind；recharts 额度曲线

## 故障排查

| 现象 | 处理 |
|---|---|
| 页面黑屏 | 理论上已被三层装甲拦截为可见错误卡；若仍整页崩溃，刷新后看底部「上次会话异常退出」卡片，把错误文本提给开发者 |
| 点击继续讨论无反应 | 已修复（额度死锁自愈）；如再出现看各方向额度是否「待批准」，点「放行 50%」 |
| 接入 API 测试连接失败（跨域） | 默认 api.moonshot.cn 支持浏览器直连；第三方网关多拦截跨域，改用本地 `npm run dev`（自带代理）或让网关加白名单 |
| 摄像头/麦克风无法开启 | 浏览器地址栏权限设置中允许；系统 Chrome 实测最佳（应用内嵌浏览器无法授权） |
| 手势左右反了 | 点控制坞「换」开关 |
| 语音不响应 | 确认唤醒词「小K」后 6 秒内发言；连续失败 5 次会自动停止，重新点「启语音」 |
